# Vaibhav Sharma · Visual Designer Portfolio

The personal portfolio website for Vaibhav Sharma, a multidisciplinary visual designer specializing in UI UX design, logo and brand identity, and YouTube thumbnail packaging.

## Design Philosophy

Built according to the Systematic Graphic Atelier direction:
* Focus on typography, spatial composition, and medium specific project presentation.
* Tactile gallery chalk palette (#F5F5F2), carbon ink (#111110), and architectural terracotta (#BF360C).
* Zero AI design cliches: no neon gradients, no glassmorphism, and no synthetic metrics.

## Technical Stack

* Semantic HTML5
* Vanilla CSS3 (style.css)
* Vanilla ES6 JavaScript (script.js)
* Typography: Plus Jakarta Sans and JetBrains Mono via Google Fonts
* Zero external dependencies

## Deployment

Configured for immediate deployment on Vercel, GitHub Pages, or any static web host via vercel.json.
